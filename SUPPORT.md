# Support

## Getting help

- **Usage questions, ideas, show-and-tell:** use
  [GitHub Discussions](../../discussions) on this repository (categories
  configured under `.github/DISCUSSION_TEMPLATE/`).
- **Bugs, defects, or hardware-validation results:** open an issue using the
  matching template under `.github/ISSUE_TEMPLATE/`.
- **Security vulnerabilities:** see [`SECURITY.md`](SECURITY.md) — do not
  use public issues or discussions.

## Before asking

1. Check [`docs/troubleshooting.md`](docs/troubleshooting.md) — it covers
   known-tricky failure modes (PiKVM capture issues, ATX pulse timing,
   power-brownout symptoms).
2. Check open and closed issues/discussions for the same topic.
3. For hardware questions, check whether the value you need is already
   marked `TBD` in `docs/power-design.md` or `docs/wiring.md` — if so, it
   genuinely hasn't been measured yet, and a PR with that measurement is
   welcome.

## Upstream project support

MSC builds on [PiKVM](https://pikvm.github.io/pikvm/). For PiKVM-specific
issues unrelated to MSC's custom services, check the
[PiKVM Handbook](https://pikvm.github.io/pikvm/) and upstream project first.

## Response expectations

This is currently a solo/small-scale open-source project without a support
contract or SLA. Response times are best-effort.
